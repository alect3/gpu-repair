# Board B

- Model: Zotac RTX 3090 Trinity
- Serial: 0091224540
- Status: short on the 5V circuit

## Symptoms

- 5V rail measures as a short.

## Findings

- Resistance to ground is normal on 12V, 3.3V, 1.8V, PEX, core and memory rails
  (measured 2026-09-05).
- Two capacitors and a resistor array have fallen off (same as Board A, see
  [common.md](../common.md)).
- 12V input path from the 8-pin connectors to the VRM input is intact
  (continuity, 2026-09-05).
- The parts were re-soldered before any testing began, so every measurement
  in the log was taken with them in place.
- The resistor array was replaced with two discrete 1.5 kohm resistors.
  One reads 1.5 kohm in place, matching Board A. The other reads 0 ohm in
  place where Board A's reads 1.0 kohm (1.5 kohm with a parallel path, so
  normal). Both re-fitted caps read 0 ohm in place, on both boards. An
  in-place 0 ohm may just be the shorted 5V net, so each part has to be
  lifted to be judged. But the second resistor is the only reading that
  differs between the two boards, which makes it the first to lift.

## Log

### 2026-09-05

- Two capacitors and a resistor array had fallen off (same as Board A). Re-soldered
  them before testing.
- Found what appears to be a short on the 5V circuit, with the parts on.
- 12V rail resistance to ground is fine. Short is on 5V only so far.
- 1.8V rail resistance to ground is fine.
- PEX rail resistance to ground is fine.
- Core and memory rail resistance to ground seem normal.
- 3.3V rail resistance to ground is fine.
- Continuity from 8-pin 12V pins to VRM input is fine.
- Slot 12V fingers to the core VRM high-side FET drains: about 50 kohm,
  same as Board A. By design.
- Measured across the two discrete 1.5 kohm resistors in place: 1.5 kohm
  and 0 ohm. Board A reads 1.5 kohm and 1.0 kohm at the same positions.
- Both re-fitted capacitors read 0 ohm across them, unpowered. Same on
  Board A. Note this also means the 0 ohm across the resistor may be the
  rail short rather than the resistor itself.

## Next steps

Same procedure as Board A, since both have the 5V circuit shorted at the
same spot:

- Start with the resistor that reads 0 ohm (1.0 kohm in place on Board A).
  Lift one end, measure it alone and the pads alone. Also check its
  placement against Board A and against the original array's footprint: a
  discrete bridging two pads the array kept separate would short that node.
  Then each cap, then the other resistor.
  After each lift, measure the part on its own and the pads on their own.
  - Part reads 0 ohm on its own: it is bad (cracked cap or wrong resistor).
    Replace with a new one.
  - Pads still read 0 ohm with the part lifted: the short is elsewhere on
    the net. Keep going.
- If all four parts are lifted and 5V still reads 0 ohm to ground, the
  short is most likely the regulator IC on the back. Lift or remove it and
  re-measure.
- Fit new parts (1.5 kohm resistors; cap values TBD, read the markings on
  Board A's originals or measure a lifted good one) and confirm 5V to
  ground is normal before powering.
