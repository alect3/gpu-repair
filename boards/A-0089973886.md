# Board A

- Model: Zotac RTX 3090 Trinity
- Serial: 0089973886
- Status: dead, no power at all

## Symptoms

- No power at all when booted. No fans, no lights, no POST.

## Findings

- Resistance to ground is normal on every rail: 12V, 5V, 3.3V, 1.8V, PEX,
  core and memory
  (measured 2026-09-05).
- Two capacitors and a resistor had fallen off (same as Board B, see
  [common.md](../common.md)). Re-soldered before testing began. 5V reads
  normal to ground, so the re-fit on this board did not introduce a short.
- 12V input path from the 8-pin connectors to the VRM input is intact
  (continuity, 2026-09-05).
- Suspected to be a different fault from Board B. The missing parts alone
  would not explain a total no-power condition, so something else is wrong.

## Next steps

No rail is shorted and the 12V input path is intact and matches Board B.
Everything left needs the card powered. Most likely the enable/sequencing
logic.

- Unpowered checks are exhausted. Everything below needs the card powered.
- With the card powered, confirm 12V is present on the board side of each
  8-pin connector and the PCIe slot 12V pins.
- Confirm 12V reaches the VRM input (high-side FET drains or the input
  bulk capacitors) for the core and memory phases.
- If 12V is present at the VRMs but nothing switches on, check the
  enable/power-good chain: PWRGD from the slot, the 3.3V and 5V standby
  supplies, and the VRM controller enable pins.
