# Board A

- Model: Zotac RTX 3090 Trinity
- Serial: 0089973886
- Status: dead, no power at all

## Symptoms

- No power at all when booted. No fans, no lights, no POST.
- The PC itself ran fine with the card installed. The PSU did not trip, so
  the card is not shorting under power. It is simply not enabling.

## Findings

- Resistance to ground is normal on every rail: 12V, 5V, 3.3V, 1.8V, PEX,
  core and memory
  (measured 2026-09-05).
- Two capacitors and a resistor had fallen off (same as Board B, see
  [common.md](../common.md)). Re-soldered before testing began. 5V reads
  normal to ground, so the re-fit on this board did not introduce a short.
- 12V input path from the 8-pin connectors to the VRM input is intact
  (continuity, 2026-09-05).
- Suspected to be a different fault from Board B. The missing parts alone
  would not explain a total no-power condition, so something else is wrong.

## Next steps

No rail is shorted, the 12V input path is intact and matches Board B, and
the PC ran fine with the card in. So it is not a short under power. The
card is not enabling: either 12V is not arriving, or the sequencing chain
is not starting the regulators.

Bench setup: card on a powered PCIe riser (riser fed from the spare ATX
PSU, no PC needed for this stage). The riser supplies slot 12V and 3.3V.
Same ATX PSU on the 8-pins, jumpered on with PS_ON to ground. The slot
has no power-good line, only PERST# (reset), and the small rails should
come up without it. A 12V headlight bulb in series with the 8-pin 12V is a cheap
current limiter: dim is normal, bright is a short.

Powered. 12V on the 8-pins confirmed. Every small rail is dead, so the
sequence is not starting at all. Next, in order:

1. Riser 3.3V confirmed. Optionally confirm it on the card side at a
   capacitor just behind the edge connector.
2. 12V at the VRM input bulk capacitors for core and memory.
3. Top left GS9216: measure AIN (pin 7, expect 12V), VCC (pin 21, expect
   about 5V) and EN (pin 2, expect above 1.6V). See notes/gs9216.md for the
   table of what each combination means.
4. Bottom left regulator (about 300 mV, assumed 1.8V): read its marking,
   then measure input and enable the same way.
5. Look for further small regulators, including on the back of the board.
   - No input: the 12V feed to it is broken.
   - Input but no output and enable low: something upstream is holding it
     off, or the enable resistor is one of the re-fitted parts.
   - Input, enable high, no output: dead regulator.
6. Compare every reading with the same points on Board B once its 5V short
   is fixed. Same board, so the numbers should match.
7. Only once the small rails are up does the rest of the chain (on-board
   power-good, core, memory) mean anything.
