# Board A

- Model: Zotac RTX 3090 Trinity
- Serial: 0089973886
- Status: dead, no power at all

## Symptoms

- No power at all when booted. No fans, no lights, no POST.
- The PC itself ran fine with the card installed. The PSU did not trip, so
  the card is not shorting under power. It is simply not enabling.

## Findings

- Resistance to ground is normal on every rail: 12V, 5V, 3.3V, 1.8V, PEX,
  core and memory
  (measured 2026-09-05).
- Two capacitors and a resistor had fallen off (same as Board B, see
  [common.md](../common.md)). Re-soldered before testing began. 5V reads
  normal to ground, so the re-fit on this board did not introduce a short.
- 12V input path from the 8-pin connectors to the VRM input is intact
  (continuity, 2026-09-05).
- Suspected to be a different fault from Board B. The missing parts alone
  would not explain a total no-power condition, so something else is wrong.

## Next steps

No rail is shorted, the 12V input path is intact and matches Board B, and
the PC ran fine with the card in. So it is not a short under power. The
card is not enabling: either 12V is not arriving, or the sequencing chain
is not starting the regulators.

Bench setup: card on a PCIe riser in a PC for the slot side (3.3V, 12V,
PWRGD, reset). Spare ATX PSU on the 8-pins, jumpered on with PS_ON to
ground. A 12V headlight bulb in series with the 8-pin 12V is a cheap
current limiter: dim is normal, bright is a short.

Powered, in this order:

1. 12V present on the board side of each 8-pin and on the slot 12V fingers.
2. 12V present at the VRM input bulk capacitors for core and memory.
3. Small rails up: 5V, 3.3V, 1.8V. The 5V circuit carries the re-fitted
   parts, and it is the rail that failed on Board B. If 5V is missing here,
   the two boards may share a cause: B failed short, A failed open.
4. If the small rails are up but core and memory stay at 0V, check the
   enable chain: PWRGD from the slot, then the EN pin on the core and
   memory VRM controllers.
5. If every rail is up and the card is still dark, look at the GPU itself:
   crystal running, BIOS chip being read.
